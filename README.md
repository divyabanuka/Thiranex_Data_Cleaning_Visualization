# Thiranex Data Cleaning & Visualization

## 📌 Project Overview

This project was completed as part of the **Thiranex Internship – Task 1: Data Cleaning & Visualization**.

The project focuses on cleaning and preprocessing a raw dataset and preparing it for analysis and visualization using Python.

## 🎯 Objectives

- Handle missing values
- Identify and remove duplicate records
- Remove unnecessary spaces
- Standardize text data
- Handle outliers
- Perform data preprocessing
- Create meaningful visualizations
- Extract useful insights from the dataset

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## 🧹 Data Cleaning Process

The following data cleaning techniques were performed:

1. Loaded and reviewed the raw dataset
2. Checked the structure and contents of the dataset
3. Identified missing values
4. Filled missing numerical values using median values
5. Checked for duplicate rows
6. Removed duplicate records
7. Removed extra spaces from text columns
8. Converted text values to lowercase
9. Identified and handled outliers
10. Prepared the cleaned dataset for analysis and visualization

## 📊 Data Visualization

Data visualization was performed using **Matplotlib** and **Seaborn** to understand patterns, distributions, and relationships within the cleaned dataset.

The visualizations help present the results of the data analysis in a clear and understandable way.

## 🔍 Key Outcomes

- Improved the quality and consistency of the raw dataset
- Successfully handled missing numerical values
- Removed duplicate records
- Standardized text-based columns
- Processed potential outliers
- Prepared the dataset for further analysis
- Generated visual representations of the data
